# 实施计划

本文件是总体规划。它特意具体说明了第 1-2 阶段（现在可构建），并明确了第 3-4 阶段（取决于人类选择、真实电影和第 1 阶段的结果）。

---

## 第 1 阶段 — 范围综述 *（自动；进行中）*

**可交付成果**：对计算标注工具的完整范围综述，以逻辑语义层次结构组织，并附有描述和建议（同类最佳与可能冗余）。

**方法：** 研究代理的扇出，每项特征子类一个，每个代理在网络资源中建立当前（2023-2026）工具的结构化目录，然后进行横切分析（层次结构、冗余、输出模式、部署可行性）和综合。

**涵盖的特征类别**

- **视觉**
  - 低级静态（亮度、对比度、颜色、空间频率、边缘）
  - 高级静态（对象、场景/地点、属性）
  - 面孔、身体、目光、面部表情
  - 动态/运动（光流、运动能量、切割检测）
  - 动作和事件识别（视频理解）
  - 显著性、美观性、深度
- **音频**
  - 低级声学（响度、音高、频谱、MFCC、起始点、节奏）
  - 高级音频（声音事件、场景、音乐与语音、MIR）
  - 语音（ASR + 时间戳、分类、韵律、声音效果）
- **语言/语义**
  - 低级词汇和单词级（频率、具体性、情感规范、惊讶、POS、NER）
  - 句法和语法（解析、复杂性、共指、对话行为）
  - 高层语义、话语和叙述（嵌入、主题、连贯性、故事弧）
- **社交/情境/情感**
  - 社交和人际（代理人、谁与谁交谈、互动类型、心理理论）
  - 情境、模式、脚本和事件分段（事件边界、情境模型）
  - 情感和情感（多模态效价/唤醒+分类；描述与引发）

**输出（写在 `docs/scoping_review/` 下）：** `00_overview.md`、`01_hierarchy.md`、每类目录部分、`08_redundancy.md`、`09_recommendations.md`。架构和部署输出位于`schema/`和`docs/design/`。

## 第 2 阶段 - 处理流程构建 *（等待第 1 阶段人工确认）*

1. **功能选择检查点** - 人类开发人员审查第一阶段的建议并冻结最终的功能/模型集（核心层与扩展层）。
2. **模型部署** - 对于每个选定的模型：下载 + 本地固定（HF/torch），或在本地不可行的情况下构建瘦 API 客户端。每个都存在于统一接口后面的`src/nfe/extractors/`中：`extract(stimulus, time_grid) -> {feature: array_over_time, metadata}`。
3. **摄取**——接受电影或故事；解复用视频帧（可配置采样）和音频；生成带时间戳的转录本（ASR 或提供的），为语言/社交/情境模型提供数据。
4. **通用网格重采样** — 将每个原始采样率功能映射到配置的网格（默认 1 Hz），记录每项特征的原始采样率和重采样方法。
5. **Emit** — 每个刺激写入一个分层标注文件（参见 `schema/`），`NaN` 用于不适用的功能，并为以后的人工标注保留插槽。
6. **MATLAB 阅读器** — `matlab/readAnnotations.m` + 帮助程序将标注加载到 MATLAB 结构体/表中。

**适用性规则：** 刺激方式（视频/音频/文本）决定运行哪些课程；其余的发出`NaN`，因此输出形状在刺激下保持不变。

## 第三阶段——语料库标注

- 从用户提供的媒体和可查找/可下载的源中组装语料库（尊重许可）。
- 维护刺激清单（身份、来源、方式、持续时间、权利）。
- 在语料库上运行第 2 阶段处理流程；缓存每个模型的输出；将标注存储在`annotations/output/`中。

---

## 第 4 阶段 — 分析和传播

- **MATLAB 分析** 跨所有刺激加载标注：描述性结构、以刺激类型为条件的跨要素相关性、标注集的主要组成部分，以及特征类别如何随时间关联的网络图（通过可视化）。
- **综述论文**记录了模型/算法以及措施之间的经验关系。
- **交互式网络界面**用于搜索特定功能较高的电影/故事片段。
- **实验设计工具**：选择刺激片段，使主要标注主成分之间的方差最大化，同时最大化特征时间序列的独立性 - 形式上，最优设计目标（例如，最大化选定集上主要成分的行列式/D-最优性），应用于语料库以产生高方差、低冗余的刺激集。

## 为人类开发者开放决策（第 1 阶段→第 2 阶段）

- 常用网格速率（默认 1 Hz）以及是否发出多个速率。
- 核心与扩展功能层成员资格。
- 输出容器格式（`schema/`中生成的推荐）。
- 仅 API 大型模型与仅本地约束的预算/需求。
- 第三阶段语料库采购的许可政策。
