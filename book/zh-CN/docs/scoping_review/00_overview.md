## 主要结论

故事片、电视节目和口头叙事把感知、语言、社会认知与情感放回连续的日常情境中，因此成为认知与情感神经科学的重要实验材料。真正的难点是把整段视听材料转换成足够密集的特征序列，并与脑活动记录使用同一条时间轴。研究者可以按秒、按帧，也可以按功能磁共振成像（fMRI）的重复时间（TR）对齐。本综述梳理了完成这些测量的工具，并从中选出小型实验室可部署的组合。

我们从两个角度组织特征。**信号来源**区分视觉（像素）、音频（波形）和语言（对齐了时间戳的转写文本）；在每种来源内部，又可以从低层信号统计一直追踪到高层语义。**表征内容**则区分社会互动、情境和情感。这三类通常需要综合前几类的信息。例如，面部朝向是一项视觉测量，两个人是否共同关注一个物体，则是由多种线索推断的社会互动特征。

多数子类已有成熟的开源工具，通常一块消费级 GPU 就能运行，许多工具只需 CPU。原文推荐的组合包括：

- **视觉**：scikit-image、OpenCV、pyrtools 和 SHINE 计算低层统计；SEA-RAFT、pymoten 和 TransNetV2 描述运动与镜头结构。SigLIP 2、DINOv2/v3 和 Qwen2.5/3-VL 提取画面语义与动作；OpenFace 3.0、InsightFace 和 MMPose 处理面孔、身份、视线与姿态。
- **音频与语音**：librosa、openSMILE 和 Parselmouth 提取声学及音质指标；BEATs 和 CLAP 识别声音事件；faster-whisper、WhisperX 和 pyannote 用于转写，以及确定“谁在何时说话”。
- **语言**：spaCy 与 SUBTLEX、Brysbaert、Warriner、NRC 等词库配合，提供逐词特征。Qwen3-Embedding 等模型的嵌入以及语言模型的隐藏状态，可用于分析话语连贯性和建立神经影像编码模型。
- **跨模态特征**：视频语言模型可以融合前述线索。audeering wav2vec2、HSEmotion 和 GoEmotions 分别估计声音、面部和文本所表达的情感；GSBS 或 BrainIAK 的隐马尔可夫模型可用于估计事件边界。

每项标注都应说明两个容易混淆的问题。其一，情感属于谁？人物表达的情感和观众感受到的情感有各自的参照标准，应分别记录。其二，算法最初按什么单位测量？帧、时间窗、话语、事件或镜头的结果最终都可能汇总到同一秒，或同一个 TR；只有保留原始时间单位，才能正确解释汇总值。

## 简介

### 动机

几十年来，认知神经科学青睐严格控制的最小刺激——孤立的单词、光栅、静态面孔——因为它们使得从刺激到神经反应的映射变得可解释。这种控制是有代价的：它剥夺了认知正常运作的时间连续性、多模态丰富性和社会情感背景。向**自然主义范式**的转变——看电影、听故事——恢复了生态有效性，并被证明是非常富有成效的，使得事件分割、叙事理解、社会推理和个体之间共享神经反应的工作成为可能。

方法论上的问题是，电影或故事本身并不是一个自变量。为了将大脑活动与刺激联系起来，刺激必须首先被“标注”：分解为定量特征时间线——亮度和运动能量、说话者身份和词汇惊异度、描述情感和事件边界——每个时间线都采样得足够密集，以跟踪逐秒的变化，并与神经记录的同一时钟对齐。从历史上看，这是手工完成的，这是缓慢的、主观的，并且不可能扩展到故事片。过去十年中计算机视觉、音频和语言模型的爆炸式增长使得“自动化”逐秒标注变得可行，但它也产生了令人眼花缭乱且快速变化的工具景观。例如，想要针对“社交互动强度”或“视觉杂乱度”建立每 TR 回归量的研究人员面临着数十个冗余度、成熟度和硬件需求不明确的候选模型。这篇评论的存在是为了使该景观可以导航。

### 功能分类一览

我们沿着两个轴对标注特征进行分类。第一个是**模态**，信号源：视觉流 (1)、音频波形 (2) 和时间对齐的语言记录 (3)。第二个是**表征层面**，从原始信号到意义的攀登：低级感知统计、中级结构和高层语义——在视觉和音频中保留静态与动态的划分。顶层是三个**跨模态类别**，按*它们代表的内容*组织：社交（4），描述人际内容；情境 (5)、设置、模式、脚本和事件结构；情感（Affect）（6），即描述和引发的情感。该树中的每个叶子都是一个特征组，具有稳定的点地址（例如`visual.lowlevel_static.color`或`affect.depicted.vocal`）、模态和级别标签、时间单位、开始/持续时间、值和出处。至关重要的是，跨模态类不会复制值；而是复制值。它们存储对贡献叶子的“引用”，使谱系变得明确。语言子类充当有意的接缝——语音到语言工具（ASR、二值化、韵律）是根据波形计算的，但生成语言基础，因此它们位于语言类的头部，同时引用而不是复制声学层。

### 本次审查的方法

我们进行了范围综述（而不是系统有效性审查），因为目标是覆盖范围的广度和实践方向，而不是汇总效应大小。对于层次结构的每一片叶子，我们调查了当前的开源和 API 工具生态系统，优先考虑以下工具：(a) 发出时间解析的、时间线可对齐的输出，(b) 进行记录和维护，以及 (c) 可由小型实验室在适度的硬件上部署。每个工具的特点是其具体输出（每个时间单位产生什么值）、其计算配置文件（CPU/GPU/API）、其本机时间粒度和推荐层（包含/包含如果资源/替代/删除）。对于每个子类，我们确定一个 *一流的* 默认集和标志 **可能冗余** 工具——重叠的选项，运行多个工具几乎买不到什么。这种冗余分析是经过深思熟虑的：它将压倒性的菜单转换为可防御的最小处理流程。

### 头条推荐

我们的核心建议是抵制一切都由自己掌控的诱惑。对于每个子类，一小部分重叠的成熟工具捕获几乎所有可用信号；附加模型大多是冗余变体。执行摘要中提到的易于处理的一流处理流程让单个实验室可以在一个消费级 GPU 上对所有六个类别的完整故事片进行标注。重复出现的决策点是实用的，而不是奇特的：要许可哪些规范数据库和 LLM、什么窗口步长设置时间粒度，以及如何将异构单元重新采样到共享的每秒时钟上。最后，我们强调两个不可协商的模式字段 - `temporal_unit` 和 `depicted_vs_elicited` 标志 - 作为最有可能防止下游对这些功能流进行无声误解的保障措施。
