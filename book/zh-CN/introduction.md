# 电影与故事的叙事特征提取

看电影时，画面有多亮？这一秒谁在说话？人物的表情何时发生变化？本项目把这些问题转化为沿时间轴排列的计算标注，用于研究人在自然情境下的知觉、语言、社会认知与情感。

> **原作与中文版**　感谢 CANlab（Tor Wager Lab）开发叙事特征提取工具、整理研究资料并编写英文原书。本学习站由 zh1peng 维护，在原书基础上提供简体中文译文和译者注，方便阅读与对照。请参阅 [CANlab 英文原书](https://canlab.github.io/narrative_feature_annotations/) 和 [原项目仓库](https://github.com/canlab/narrative_feature_annotations)。

## 从一部影片到一组逐秒标注

输入可以是一部影片、一段有声故事，也可以是一篇文字故事。处理流程调用适合该材料的模型，从视觉、音频、语言、社会互动、情境和情感六个方面提取特征，再将结果对齐到同一条时间轴。不同材料使用同一套通道：例如，有声故事也保留视觉通道的位置，其中的数值记为缺失。这样就能把不同材料的数据整理成矩阵，放在一起分析。

> **译者注**　“通道”（channel）指沿时间记录的一项特征，如画面平均亮度。“1 Hz”表示每秒有一个标注时点。同一秒的亮度可以是一个数，画面的语义表示则可以是一组数。缺失值与测得的零有不同含义：纯音频没有画面可测，黑色画面的亮度却可以接近零。

## 项目规模

- 共标注 **107 份刺激材料**，总时长约 **10.1 小时**，其中有 77 份视听材料、29 份纯音频材料和 1 份纯文本材料。
- 每份材料采用 **103 个通道**，覆盖六大特征类别，统一对齐到 1 Hz 时间网格。
- 模型优先在本地运行，支持 Apple Silicon 的 GPU 或 CPU。输出包括 HDF5 数据文件和 JSON 清单，项目另提供 MATLAB 读取工具。
